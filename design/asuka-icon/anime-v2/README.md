# ASUKA anime agent icon v2

## Direction

An original anime-inspired AI coding agent. The icon keeps the ASUKA coral family, then adds a more youthful character-led silhouette: coral hair, mint eyes, an energetic wink, a gaming headset, and a terminal prompt on the ear cup.

This is an original character direction. It does not reproduce an existing anime character or trademarked costume.

## Palette

- Signal coral: `#FF4F87`
- Peach orange: `#FF9A3D`
- Hair pink: `#FF3E7F`
- Mint cyan: `#35DDD0`
- Lemon accent: `#FFE45C`
- Ink: `#241C3A`
- Warm ivory: `#FFF1DA`
