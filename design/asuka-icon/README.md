# ASUKA app icon

## Design intent

The mark combines a capital A, a terminal prompt (`>`), and a bird-like upward silhouette. The result is intended to read as an AI coding agent without relying on the usual chatbot bubble, orbit, or cluster-of-sparkles vocabulary.

## Palette

- Sunrise coral: `#FF6B3D`
- Deep coral: `#E92E47`
- Ink: `#171318`
- Warm ivory: `#FFF2D8`
- Golden signal: `#FFD05A`

## Files

- `asuka-app-icon.svg`: recommended primary icon
- `asuka-app-icon-dark.svg`: dark-surface treatment
- `asuka-mark.svg`: transparent symbol for UI, documentation, and favicon use
- `asuka-app-store.svg`: full-bleed square master with no transparency or pre-rounded corners

PNG exports are generated at 1024, 512, 256, and 128 pixels. Use `asuka-app-store-1024.png` for store submission and let the operating system apply its own icon mask. Keep the symbol inside the existing safe area and do not add text to the app tile.
